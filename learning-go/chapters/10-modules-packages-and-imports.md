# Глава 10. Modules, Packages, and Imports

- **PDF:** 247–286 (печать 223–262)
- **Якоря:** module, package, export, internal, init, MVS, go.mod, vendor

Репозиторий → модуль (версия как единица) → пакеты (каталоги). Два модуля в одном репо нежелательны: версии склеиваются. Export — **заглавная буква**; это API, его документируют. Пакет `internal` виден только родителю и соседям. Круговые импорты запрещены. `init` — побочные эффекты, лучше избегать; blank import (`_`) для регистрации драйверов — устаревший паттерн, в своём коде регистрировать явно.

Сторонний код — исходники в бинарник. Версии: **Minimal Version Selection**, import compatibility (тот же import path = обратная совместимость minor/patch). v2 — другой путь модуля. Vendor, proxy, checksum, workspaces, retract. Пакетные комментарии / `pkgsite`.

# Глава 14. The Context

- **PDF:** 373–394 (печать 349–370)
- **Якоря:** context.Context, WithValue, WithCancel, deadline, Done, Cause

Метаданные запроса в Go не threadlocal (у горутин нет id, это «магия»). Context — обычный параметр, **первый**, имя `ctx`. По умолчанию данные — явные аргументы. **Values** — обходной путь, когда сигнатура фиксирована (HTTP handler): JWT-пользователь, request GUID, уровень лога. Context immutable: `WithValue` возвращает child. Ключ — свой unexported тип, не строка `"id"`. В бизнес-логику значения **копируют в параметры**; из context наружу данные не выносят.

**Cancel / deadline** — когда останавливать работу: отмена соседних горутин, таймаут сервера как общего ресурса. `WithCancel`, `Done()`, `Cause`. Свой долгий цикл — периодически `context.Cause`. HTTP/БД — просто прокидывать ctx; они сами слушают отмену.

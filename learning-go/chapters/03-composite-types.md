# Глава 3. Composite Types

- **PDF:** 61–90 (печать 37–66)
- **Якоря:** array, slice, append, capacity, map, comma ok, struct

**Массив** почти не используют: длина входит в тип (`[3]int` ≠ `[4]int`), функции «на любой размер» не напишешь. Массивы нужны как backing store для **слайсов**. У слайса длина не часть типа, zero — `nil`, `==` между слайсами нельзя (с 1.21 — `slices.Equal`). `append` возвращает слайс; результат надо присвоить. Capacity: когда length = cap, runtime выделяет новый backing array (рост не на 1).

**Map** — hash table; запись в `nil` map — panic; чтение отсутствующего ключа даёт zero, отличие — **comma ok**. Map/slice не сравнимы. Слайс — последовательность / порядок; map — ключ не «следующее целое». **Struct**: литерал с именами полей устойчивее к добавлению полей; анонимные структуры — без имени типа.

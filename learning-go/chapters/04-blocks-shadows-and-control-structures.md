# Глава 4. Blocks, Shadows, and Control Structures

- **PDF:** 91–116 (печать 67–92)
- **Якоря:** block, shadowing, if, for-range, switch, goto

Идентификаторы живут в блоках (пакет, файл, функция, `{}`, plus у `if`/`for`/`switch` свои). Одноимённая переменная во внутреннем блоке **тенит** внешнюю: `:=` легко делает это незаметно — переиспользует только имена **текущего** блока. Можно затенить даже импорт (`fmt`).

Четыре `for`: полный, только условие, бесконечный, **for-range**. Range предпочитают для встроенных коллекций и строк (руны, не байты); полный `for` — когда идёшь не с начала до конца. Цепочки `if/else` для связанных условий лучше **blank switch**. `goto` есть, но почти всегда вреден; допустим, если без него код читается хуже.

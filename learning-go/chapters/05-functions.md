# Глава 5. Functions

- **PDF:** 117–142 (печать 93–118)
- **Якоря:** named return, blank return, closure, defer, call by value

Функции — значения (сигнатура = тип). Несколько возвратов — норма; именованные возвраты путают из‑за shadowing и того, что `return a, b` игнорирует уже записанные имена. **Blank/naked return не использовать** — читатель должен искать, что вернулось. Анонимные функции и замыкания; пакетные функции-переменные лучше не мутировать.

`defer` — LIFO, аргументы считаются сразу, тело после `return`. Go **call by value**; «иногда значение — указатель». Содержимое map в функции меняется; у slice меняются элементы, но `append` длину снаружи не двигает. Ошибки и валидация входа — не опция: «хрупкие программы не пишут».

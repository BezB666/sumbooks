# Глава 2. Predeclared Types and Declarations

- **PDF:** 41–60 (печать 17–36)
- **Якоря:** zero value, untyped literal, var, :=, const, unused variable

Главное правило главы: код должен **делать намерение явным**. У любой незаданной переменной есть zero value (не «мусор» как в C). Приведения типов только явные; «truthy» нет — в `bool` только через сравнение. Литералы без типа, пока не привязали к переменной.

Стиль объявления сам документ: внутри функции чаще `:=`; `var x int` — когда нужен именно zero; длинный `var` с типом — когда литерал не того типа. `:=` вне функций нельзя и легко тенит переменные. Неиспользованная переменная — ошибка компиляции (пакетные — нет, ещё причина их избегать). Неиспользованные `const` компилятор глотает: они считаются на этапе компиляции.

# Глава 15. Distribution Patterns

- **PDF:** 412–439 (печать 387–414)
- **Якоря:** Remote Facade, Data Transfer Object, First Law

Следствие гл. 7: объекты не распределять; на границе процесса — грубый фасад и пачка данных. Inter-process на одной машине уже достаточно дорог.

| Паттерн | Когда |
|---|---|
| Remote Facade | нужен remote-доступ к мелкозернистой модели (UI↔домен в разных процессах, servlet и домен на разных серверах). Внутри одного процесса не нужен. Фасад только делегирует, сам почти без логики |
| Data Transfer Object | несколько полей одним remote-вызовом (Java не вернёт кучу out-параметров). Лучше послать лишнее, чем звонить ещё раз. Не сериализовать граф Domain Model; сборка через Mapper/assembler. Не путать с Value Object (гл. 18); в EJB это часто звали «value object» |

# Глава 16. Offline Concurrency Patterns

- **PDF:** 440–479 (печать 415–454)
- **Якоря:** Optimistic Offline Lock, Pessimistic Offline Lock, Coarse-Grained Lock, Implicit Lock

Замки на бизнес-транзакцию, которая не влезает в одну системную. Сначала попробовать уместить в один запрос или прожить с long transaction (гл. 5).

| Паттерн | Когда |
|---|---|
| Optimistic Offline Lock | конфликт двух бизнес-транзакций редок; проще в коде, лучше liveness. Дефолт Fowler. Если пользователь час заполнял лизинг и в конце «отклонено» — вера в систему падает, тогда pessimistic |
| Pessimistic Offline Lock | конфликт частый или цена конфликта неприемлема (работу нельзя выбрасывать). Узнаёшь о блоке рано; сложнее и душит liveness |
| Coarse-Grained Lock | замок на группу (агрегат: лизинг + активы). Дешевле брать/отпускать. Не выдумывать неестественные связи ради перфоманса |
| Implicit Lock | почти всегда, как только есть каркас: один забытый замок ломает схему. Прикладной код не зовёт lock вручную |

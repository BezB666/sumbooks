# Глава 8. Component-Based Thinking (Компонентное мышление)

- **PDF:** 144–167 (печать 132–155)
- **Якоря:** component (компонент), technical partitioning (техническое разбиение), domain partitioning (доменное разбиение), Conway’s law (закон Конвея), Inverse Conway Maneuver (обратный манёвр Конвея), modular monolith (модульный монолит)

**Component** (компонент) — физическая упаковка модуля (jar, dll, gem). Архитектор работает на этом уровне, не микроменеджит классы. **Technical partitioning** (техническое разбиение) — слои (presentation / представление / business / бизнес / persistence / персистентность); **domain partitioning** (доменное разбиение) — вокруг workflow (потока работ; CatalogCheckout), как modular monolith (модульный монолит) / МС. Conway (Конвей): оргструктура копируется в дизайн; Inverse Conway Maneuver (обратный манёвр Конвея) — двигать команды под желаемую архитектуру.

Поток: начальные компоненты → требования → роли → characteristics (характеристики) → пересборка. Гранулярность: слишком крупные = высокая внутренняя связность. Финальный выбор monolith vs distributed (монолит vs распределённый) — по числу квантов (один набор ilities (характеристик на «-ость») → монолит выгоднее).

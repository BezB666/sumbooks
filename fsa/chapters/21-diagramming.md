# Глава 21. Diagramming and Presenting Architecture (Диаграммы и презентация архитектуры)

- **PDF:** 411–423 (печать 399–411)
- **Якоря:** representational consistency (согласованность представления), C4, UML, ArchiMate, infodeck (инфодек)

Идея без убеждения менеджеров и разработчиков не живёт. **Representational consistency** (согласованность представления): прежде чем зумить, показать, где кусок сидит в целом.

Стандарты: **UML** (из class/sequence / классов/последовательностей ещё живы); **C4** (Simon Brown) — Context (контекст), Container (контейнер), Component (компонент), Class (класс); лучше для монолитов, хуже для МС; **ArchiMate** — лёгкий EA (enterprise architecture / корпоративная архитектура). Дальше свои guidelines (рекомендации; заголовки, не цепляться к красивому артефакту). Презентации: incremental builds (поэтапные построения), манипуляция временем; infodeck (инфодек) ≠ слайды «половина истории».

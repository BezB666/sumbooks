# Глава 12. Microkernel Architecture Style (Стиль микроядра)

- **PDF:** 206–221 (печать 194–209)
- **Якоря:** Microkernel (микроядро), plug-in architecture (архитектура плагинов), core system (ядро системы), plug-in components (компоненты-плагины)

Монолит из **core system** (ядра системы) + независимых **plug-in** (плагинов; продукт на площадке клиента, IDE, налоговые формы 1040). Запросы идут через ядро → квант всегда 1. Единственный стиль, который бывает и **domain-** (доменно-), и **technically partitioned** (технически разбитый; конфиги по клиентам / кастомизация).

Сильные: **simplicity** (простота), **cost** (стоимость). Слабые: **scalability** (масштабируемость), **fault tolerance** (отказоустойчивость), **elasticity** (эластичность; монолит). **Testability / deployability / reliability / modularity / extensibility** (тестируемость / развёртываемость / надёжность / модульность / расширяемость) ~3 (изоляция в плагинах, runtime-подключение). **Performance** (производительность) ~3: приложения меньше Layered, можно отключить ненужные плагины (пример WildFly).

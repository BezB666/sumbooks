# Глава 3. Modularity (Модульность)

- **PDF:** 59–82 (печать 47–70)
- **Якоря:** modularity (модульность), coupling (сцепление), cohesion (связность), LCOM, afferent (афферентное), efferent (эфферентное), abstractness (абстрактность), instability (неустойчивость), distance from the main sequence (расстояние до главной последовательности), zone of pain (зона боли), zone of uselessness (зона бесполезности), connascence (со-рождение / коннасценция)

Модульность — organising principle (организующий принцип) и implicit characteristic (неявная характеристика): без неё система идёт в энтропию. Метрики: cohesion (связность; LCOM), **afferent/efferent** (афферентное/эфферентное) coupling (сцепление; Yourdon/Constantine), затем **abstractness** (абстрактность), **instability** (неустойчивость), **distance from the main sequence** (расстояние до главной последовательности).

**Connascence** (коннасценция / со-рождение; Page-Jones): два компонента connascent (со-рождённые), если изменение одного требует правки другого. Статические: Name (имя), Type (тип), Position (позиция), Algorithm (алгоритм). Динамические: Execution (исполнение), Timing (время), Values (значения), Identity (идентичность). Правила: сильные формы → слабые; чем дальше элементы, тем слабее связь. Coupling (сцепление) и connascence (коннасценция) — разные эпохи, для архитектора пересекаются. Дальше модули становятся components (компонентами).

## Distance from the Main Sequence (PDF 70–73)

Одна из немногих **holistic** (целостных) метрик структуры: считается не по одному компоненту, а по их положению относительно идеальной линии.

### Ингредиенты

**Abstractness** (абстрактность) — доля абстракций в коде, Equation 3-3:

```
A = Σma / Σmc        # FSA, стр. 70
```

где `ma` — абстрактные элементы (интерфейсы, абстрактные классы), `mc` — конкретные. Крайности обе плохи: 5000 строк в одном `main()` → `A ≈ 0`; перебор абстракций → `AbstractSingletonProxyFactoryBean`, в котором никто не разберётся, как это связано.

**Instability** (неустойчивость) — волатильность кода, Equation 3-4:

```
I = Ce / (Ce + Ca)
```

где `Ce` — efferent / outgoing coupling (эфферентное, исходящее: от скольких зависим мы), `Ca` — afferent / incoming (афферентное, входящее: сколько зависят от нас). `I → 1` — нестабилен (легко ломается от чужих правок, но и менять его безопасно); `I → 0` — стабилен. Важно: `I ≈ 0` сам по себе не хорош и не плох — он **rigid** (жёсткий), если набит конкретикой, и **stable**, если абстракциями. Отсюда и нужда смотреть `A` и `I` вместе, а не по отдельности.

### Формула

```
D = |A + I − 1|        # Equation 3-5, стр. 71
```

Обе величины — доли от 0 до 1. Идеальная линия (main sequence) — это `A + I = 1`: **чем абстрактнее модуль, тем он должен быть стабильнее**, и наоборот. `D` — расстояние до этой линии, `D = 0` идеально.

### Зоны

- **Zone of uselessness** (зона бесполезности) — правый верхний угол: слишком много абстракций, код неудобно использовать.
- **Zone of pain** (зона боли) — левый нижний угол: много конкретики, мало абстракций — код хрупкий и тяжёлый в поддержке.

Практический вывод книги: много компонент в этих зонах — сигнал **не чинить внутренности до идеала, а обходить**. Именно поэтому метрика стоит в начале главы о декомпозиции в Hard Parts: грязь не станет сервисами от желания.

### Осторожно: в двух книгах формула A разная

FSA даёт `A = Σma / Σmc`, а Hard Parts (Equation 4-1) — `A = Σma / (Σmc + Σma)`. Нормировку в диапазон 0–1 обеспечивает **только** вариант Hard Parts; с формулой FSA `|A + I − 1|` может выйти за пределы отрезка и теряет смысл «расстояния». Считая `D` по FSA, берите нормированную версию `A`. См. [concepts/distance-from-main-sequence.md](../../corpus/concepts/distance-from-main-sequence.md).

### Связь с connascence

Обе пары — про одно и то же с разных сторон. Coupling / `Ce`/`Ca` меряют связь **количественно** (сколько рёбер), connascence — **качественно** (насколько сильно придётся править соседа). `D` добавляет третий разрез: связь vs уровень абстракции. Модуль с высоким `Ce` (много исходящих зависимостей) и низким `A` — кандидат в zone of pain; лечится либо абстракцией, либо разворотом зависимости.

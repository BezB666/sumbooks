# Глава 5. Identifying Architectural Characteristics (Выявление архитектурных характеристик)

- **PDF:** 98–113 (печать 86–101)
- **Якоря:** explicit characteristics (явные характеристики), implicit characteristics (неявные характеристики), domain concerns (доменные заботы), Silicon Sandwiches, Vasa

Ilities (характеристики на «-ость») берут из домена, требований и неявного знания. Список держать коротким: generic architecture (универсальная архитектура) «на все ilities» — антипаттерн (Vasa: корабль утонул от лишних требований).

**Explicit** (явные) — в спецификации (нагрузка, i18n / интернационализация, франшизы). **Implicit** (неявные) — не пишут, но ждут: availability (доступность), reliability (надёжность), security (безопасность) почти всегда; приоритет зависит от критичности. Kata (ката) **Silicon Sandwiches**: из сценария вытаскивают только то, что меняет структуру, не весь дизайн. Ilities задают относительно друг друга (performance / производительность при каком scale / масштабе).
